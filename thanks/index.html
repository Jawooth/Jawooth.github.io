致谢 · Credits

这个站在下面这些开源项目的肩膀上搭起来。全部为 MIT / OFL 协议， 均已自托管在 source\vendor\ 与 source\fonts\（不请求任何第三方域名）。 感谢这些项目的作者。

前端库（source\vendor\）
  • XP.css 全站 UI 基础——窗口、标题栏、按钮的 XP 观感都从它来，本站在其上做了兼容层 MIT · botoxparty
  • APlayer 首页音乐播放器（歌单由本站的 fetch-netease.py 从网易云同步后静态注入） MIT · DIYgod
字体（source\fonts\ 与 vendor 内置）
  • 缝合像素字体 Fusion Pixel Font 12px 正文像素字体（按站内用字裁剪成子集，OFL 授权文本随字体附带） OFL · TakWolf
  • MS Sans Serif（像素化重制版）与 Perfect DOS VGA 437 Win XP.css 内置的两套拉丁像素字体，随 XP.css 一并分发 随 XP.css · 见其仓库
站点引擎（package.json 依赖）
  • Hexo 静态站生成引擎（v8.1.2，全部生成器与渲染器插件见 package.json，均 MIT） MIT · hexojs
  • hexo-theme-minimalism 主题基础框架（页面模板与整体布局由此改造而来） MIT · f-dong
  • hexo-blog-encrypt 文章加密（锁定版本 4.1.0，AES-256-GCM） MIT · walterlv / MikeMcl
参考过设计与思路的项目
  • 98.js.org 浏览器里复刻 Windows 98 桌面的项目——「把博客做成操作系统」这条路的前辈 MIT · 参考其桌面隐喻的组织方式
  • Microsoft Windows XP 整体视觉隐喻的来源。本站是爱好者致敬，未使用任何微软版权素材（图标、壁纸均为自制或开源替代） — 致敬对象
